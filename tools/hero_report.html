五、结论与说明

✅ Hero 评分规则保持不变；Hero 资格 = 稳定源 + 高清 Poster(≥800) + 高清 Backdrop(≥1280) + 准确匹配，缺一即淘汰（宁缺毋滥）。

⚠️ 当前入选数为 1。若入选为 0，不是 Hero 判断逻辑的问题，而是当前采集库（archive.org 冷门片/家庭录像/西语老 B 级片）在合法免费图源（Wikimedia / TMDB）上确实没有高清宣传图。 Hero 不会把 5KB 缩略图、错图、假高清塞进去凑数。

提升真实入选的路径（不降低标准）：
① 配置免费 TMDB API Key（同片 Poster+Backdrop 绑定保证，覆盖率最高）： set TMDB_API_KEY=你的key 后重跑 python tools/hero_fetch.py --source tmdb,wikimedia --run-hero；
② 向库里补充「本身在 TMDB/Wikimedia 上有高清图的影片」（主流电影 / 知名老片），自然会被 Hero 选中。

✅ 下一步：hero_fetch.py 已实现严格匹配 / 同片绑定 / 质量门禁 / URL+image hash 缓存 / 失败分类 / 限额并发；配合 TMDB Key 即可规模化产出真实 Hero。
